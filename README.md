## Como compilar e executar o Benchmark

Este projeto foi desenvolvido em Java puros, sem dependências externas. Para executá-lo via terminal, siga os passos abaixo a partir do diretório raiz do projeto:

1. **Compilar os arquivos .java:**
   ```bash
   javac src/interfaces/*.java src/algorithms/search/*.java src/algorithms/sort/*.java src/utils/*.java src/bench/Benchmark.java
   
2. **Executar o Motor de Benchmark**
   ```bash
   java -cp src bench.Benchmark
